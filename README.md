# PixiJS Particle Playground

100,000개 파티클이 마우스에 반응하는 인터랙티브 데모. PixiJS v8 + Vite.

## 조작법

| 입력 | 동작 |
| --- | --- |
| 마우스 이동 | 파티클이 반응 |
| `1` | 끌림 모드 |
| `2` | 소용돌이 모드 |
| `3` | 중력 모드 |
| `4` | 반발 모드 |
| `5` | 노이즈 흐름장 모드 |
| 클릭 | 폭발 |
| `Space` | 파티클 재배치 |

## 실행

```bash
npm install
npm run dev
```

튜닝은 `src/config.js`에서. 파티클 수, 힘 계수, 색상 매핑 전부 상수로 빼두었다.
